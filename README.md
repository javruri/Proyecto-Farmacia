# Proyecto-Farmacia
Proyecto Farmacia: Sistema de gestión para cadenas de farmacias (base de datos + web + app Android)

| Módulo | Qué resuelve |
|---|---|
|  **Directorio médico** | Médicos, especialidades y años de experiencia; asignación de pacientes bajo supervisión. |
|  **Pacientes** | Ficha, teléfonos, sistema previsional (Fonasa / Isapre) y médico de cabecera. |
| **Recetas** | Emisión con vigencia; solo el médico de cabecera puede recetar (validado por *trigger*). |
|  **Inventario y ventas** | Stock por farmacia, ofertas con fecha de inicio y término, descuento automático de existencias. |
|  **Convenios** | Contratos entre farmacias y laboratorios, con supervisor responsable y vigencia. |
|  **Estadísticas** | Boletas emitidas, distribución de fármacos y atenciones médicas. |
